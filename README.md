# Carl-Cam

Carl-Cam is a local-first Python Windows desktop camera application. It combines three live graphic filters, a hand-defined picture frame, a head-following menu and in-app personal gesture training. PySide6 provides the desktop interface, MediaPipe supplies perception, and PyTorch trains the personal gesture recognizer with optional NVIDIA GPU acceleration.

The first deliverable is a runnable application and installer with in-app personal gesture training. A creator-trained demo model and public release follow separate validation gates.

## Model provenance

The hand, short-range face, and multiclass selfie models are Google's published MediaPipe assets. Their original download URLs, SHA-256 hashes, and sizes are recorded in `src/carl_cam/assets/models/manifest.json`, alongside the Apache 2.0 license. The [hand-landmarker guide](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker/python) describes its landmark outputs and video tracking; the [segmentation guide](https://developers.google.com/edge/mediapipe/solutions/vision/image_segmenter) defines the background, hair, body skin, face skin, clothes, and accessory categories. Additional application and dependency licensing checks are required before release.
